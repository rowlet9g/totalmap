01 · 연결 확인

Whale에서 목록 읽기

  1. 지도 탭에서 동기화할 목록 하나를 엽니다.
  2. Totalmap 확장 버튼에서 분류를 선택합니다.
  3. ‘현재 지도 읽기’를 누릅니다.
  4. 이 화면에서 결과를 확인합니다.

수집 결과는 이 브라우저에만 저장됩니다. 처음에는 장소 링크가 안 잡히거나 일부만 잡힐 수 있습니다. 이 결과로 서비스별 수집기를 검증합니다.

02 · 동기화 원칙

처음에는 합치고,
다음부터는 변경만.

  • 국내 장소와 네 분류의 소속 관계를 연결합니다.
  • 삭제 판단에는 완전한 조회와 이전 기준 상태가 필요합니다.
  • 분류 이동은 새 분류에 추가한 뒤 기존 분류에서 제거합니다.
  • 충돌·미확인 장소는 확인 대상으로 남깁니다.

읽기 진단 기록

개발 검증 · 전체 스냅샷으로 계획 미리보기

진단 기록은 전체 스냅샷이 아니므로 삭제 판단에 사용하지 않습니다. 검증용 JSON 형식은 프로젝트 문서를 참조하세요. 가져온 데이터도 지도 계정에는 반영되지 않습니다.
