01 · 연결 확인

Whale에서 목록 읽기

  1. 지도 탭에서 동기화할 목록 하나를 엽니다.
  2. Totalmap 확장 버튼에서 분류를 선택합니다.
  3. 구조 확인은 ‘화면 진단 실행’, 네이버 카드 선택 후 ID 확인은 ‘네이버 상세 URL의 ID 읽기’를 누릅니다.
  4. 확장의 ‘관리 화면 열기’로 기록을 확인합니다.

확장 관리 화면의 기록은 chrome.storage.local에 저장됩니다. localhost 미리보기는 별도 저장 공간을 쓰는 데모이며 확장 기록과 연결되지 않습니다. 진단 및 상세 URL 기록은 완전한 동기화 입력이 아닙니다.

02 · 동기화 원칙

처음에는 합치고,
다음부터는 변경만.

  • 국내 장소와 네 분류의 소속 관계를 연결합니다.
  • 삭제 판단에는 완전한 조회와 이전 기준 상태가 필요합니다.
  • 분류 이동은 새 분류에 추가한 뒤 기존 분류에서 제거합니다.
  • 충돌·미확인 장소는 확인 대상으로 남깁니다.

네이버 장소 읽기 기록

상세 URL의 ID와 확인된 이름·주소 필드를 기록합니다. 각 항목의 출처를 표시하며 전체 수집 여부는 별도로 검증합니다.

읽기 진단 기록

개발 검증 · 전체 스냅샷으로 계획 미리보기

진단 기록은 전체 스냅샷이 아니므로 삭제 판단에 사용하지 않습니다. 검증용 JSON 형식은 프로젝트 문서를 참조하세요. 가져온 데이터도 지도 계정에는 반영되지 않습니다.
